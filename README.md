# Lyra — VPN для Android

Здесь публикуются готовые версии приложения **Lyra**: VPN-клиента на ядре Xray, который сам меняет сервер при переходе между Wi-Fi и мобильным интернетом.

## Как установить

1. Откройте [последний релиз](../../releases/latest).
2. Скачайте APK для своего телефона:
   - **`lyra-…-arm64-v8a.apk`** — для почти всех телефонов последних лет (≈14 МБ);
   - `lyra-…-armeabi-v7a.apk` — для старых 32-битных телефонов;
   - `lyra-…-universal.apk` — если не уверены, подойдёт любому (≈53 МБ).
3. Откройте файл и разрешите установку из этого источника, если Android спросит.

## Обновления

Lyra сама проверяет этот репозиторий и присылает уведомление, когда выходит новая версия. Обновиться можно прямо из приложения: «Настройки» → «Обновления».

## Что умеет

- Протоколы VLESS (REALITY, XTLS Vision, XHTTP, gRPC, WS), VMess, Trojan, Shadowsocks, Hysteria2; подписки и импорт из буфера или по QR-коду.
- Свои правила для Wi-Fi, мобильного интернета и конкретных Wi-Fi сетей: сервер, лучший по пингу, свой список, пауза VPN.
- Правила для отдельных приложений на каждой сети.
- «Россия напрямую», блокировка рекламы, автопереход на рабочий сервер.
